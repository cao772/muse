# 十一的动画素材

`shiyi-atlas.png` 是16格、每格96×96的透明动画图集，用内置 imagegen 根据用户授权提供的十一照片生成，再裁成固定格子并统一脚底基线。参考视频补充了坐姿与体态观察；原始照片、视频和完整生成大图不进入Git；仅提交整理后的宠物图集。

特征：棕灰虎斑额头与背部、不对称白鼻梁、白胸腹白腿、粉鼻、圆眼睛和环纹尾。它是风格化形象，相似度由主人确认；不宣称与照片完全一致。

按行依次为：坐姿、眨眼、开心、歪头；两帧走路、两帧舔爪；两帧蜷睡、两帧抬爪；认真听、好奇等待、两帧前爪动作。玩具、小碗、键盘和等待符号由程序叠加。

`python scripts/build_pet_art.py`（需Pillow）将透明图集与小窝底色合成、量化为256色，并生成`main/muse_pet_art.inc`。固件无需Pillow、PNG解码器或网络，147456字节索引和512字节RGB565色表作为const留在Flash；展开后的22帧必须分配在PSRAM，不能改回内部RAM静态大数组。

生成提示词见[shiyi-prompt.txt](shiyi-prompt.txt)。后续更换图集时保留4×4网格、96px格子和颜色背景，重建include并跑原生帧/内存预算检查；最后必须验实体板显示日志与触控。
