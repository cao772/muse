# P7｜Muse 原创像素宠物与 Codex 视觉联动

下文按开发顺序记录。当前实现以末尾“花屏修复与照片参考素材”一节为准；早期手绘像素形象已替换。

## 基线与来源
- 基于 P6 宠物农场已 CI success 的 commit `5364dd0`，只在 `feature/p7-pet-animation` 修改。
- **全部 16×16 RGB565 像素图形由仓库源码生成，无外部下载的 sprites、字体或图库许可依赖。**
- 原 P6 游戏存档结构、NVS 命名空间 `muse_pet_v1/garden` 与45秒上电时间成长行为保持不变。不需要 schema migration。

## 八种表情帧
`muse_pet_animation.[ch]` 是纯 C11、无 ESP32 和 LVGL 依赖的原生 sprite 生成器：
- Idle：陪伴
- Walk：小幅左右移动
- Sleep：久未触碰/任务空闲（30秒后）
- Happy：抚摸/喂食后的短暂开心
- Type A / Type B：已有 Codex 状态 running/starting_agent/agent_started/creating_workspace 时交替键盘帧
- Wait：已知需要用户反馈的 Codex 事件，举起提示符
- Listen：Muse 语音处理中，仅视觉表现，不额外播报

决定顺序：`需要人工反馈 > 语音处理中 > Codex运行中 > 互动开心 > 空闲睡觉 > 走动/待机`。
所有决策来自**现有 Mac USB 状态快照**，未扩大网络权限，也不会把 Agent 进程结束判为工作正式完成。
超时/Unknown 不能作为有效 Codex 工作状态；数据缺失时不绘制虚构运行/等待标识。

## 渲染策略
- 启动时生成八张 16×16 RGB565 静态图片（合计4096字节像素，不依赖 PNG/GIF/Web引擎）。
- LVGL 9.5 使用 `lv_image_dsc_t` 与 `lv_image_set_scale`，只在 pose 发生变化时替换 src；页面仍沿用200ms已有 UI timer，无新音频/游戏线程。
- 小幅步行动画只调整 Pet 容器位置；屏幕触摸和三格种植按钮不受影响。
- 未实际测试 FPS、UI 触摸阻挡、PSRAM 空闲量，实机验证前不得标记完成。

## 验收
- `tests/test_pet_native.py` 编译执行纯 C 状态模型和像素动画代码（C11、-Wall -Wextra -Werror），并覆盖七种以上帧差异、优先级、无效输入。
- Gateway Ruff/format/全量 pytest、ESP-IDF 固件 CI 必须对精确 HEAD success。
- Mac Codex 在用户许可的实体板上执行**app-only 烧录**，勿擦除 NVS/全片：对比 Idle/Walk/Sleep/Happy/Typing/Waiting/Listening，左右滑六页、三格田地、Serena 音量80、USB 音频及 Wi-Fi 断开下农场继续运行。
- 执行状态输入用受控测试任务而非生产仓库；若无法真实触发 waiting/running，标注模拟测试与真机事实的区别。

不合并 P7→P6/P5/P4/P3/P2/main，保持 Draft。

## 2026-10-09 本机外观修整与中文页

用户实机反馈原帧“有动作但有点丑”，并明确要求宠物页中文。独立子分支 `codex/p7-local-acceptance` 基于精确 P7 `0ddcd6b`，不改上游 Draft 或 main。

- 原创精灵改为 32×32 奶油色垂耳小狗：围巾、腮红、高光、脚爪与地面阴影；保留八种状态优先级。4倍整数放大，静态帧合计16 KiB（原4 KiB），不新增游戏线程。
- 宠物页使用深苔绿、奶油色、暖黄按钮，田地增加矢量嫩芽和成熟果实。保留点击/滑动处理、农场规则和 NVS schema。
- “小小农场”、心情、摸摸/零食/收获计数、喂点零食、播种/浇水/生长中/收获、说句话全部中文。嵌入 Noto Sans SC 500字重的18/24px最小字库；源、版本、SHA、许可和生成方法见 `firmware/esp32/fonts/README.md`。不把 macOS 私有字体或17MB源字体放入固件。
- 新增检查实际生成字库是否覆盖所有中文 UI 文案，连同原生 C11 状态/精灵测试，本机 **180 passed**；Ruff 和文档检查通过。
- 本机构建 app 为 `0x173ee0` / 1,523,424 字节，2 MiB app 分区剩余 `0x8c120` / 573,728 字节（27%）。不扩分区、不擦 NVS。
- 初版 P7 app-only 烧录已通过 Flash hash；用户确认“有动作”。新版中文美化 app 已 app-only 烧录，Flash hash 校验通过，启动后串口收到配置等待提示；中文清晰度、视觉效果、田地触控与断电存档需实机反馈，不能用布局预览或编译成功代替验收。

本轮保持离线等待 USB 配置：游戏已在配置前初始化。没有启用云端模型、Wi-Fi、Codex 执行或自动讲话；USB语音与存档重启仍是后续待验项。

这是一版小尺寸像素化形象，不宣称照片级还原；相似度和实体屏显示由用户确认。

十一版本本机构建成功（app `0x173d50`，分区余27%），180项测试通过，app-only烧录及Flash hash校验成功；未擦NVS。实体外观与互动待用户确认。

## 十一第二版：圆脸与生活动作

针对用户“有点不像、再可爱点、动作再多点”的反馈，扩大脸颊和瞳孔高光，保留虎斑额纹、白鼻梁、粉鼻、白胸白爪与环纹尾。新增眨眼、歪头、舔爪两帧、摇尾、蜷睡呼吸两帧；合计15张32×32 RGB565静态帧，占30 KiB像素RAM。仍复用200ms UI timer，无模型、网络或新游戏线程。

待机动作以14秒周期交替，30秒未互动后蜷睡呼吸。抚摸/喂食显示开心与歪头；等待人工反馈、语音忙、Codex工作仍优先于生活动作。原生测试覆盖整周期动作可达性、状态优先级、舔爪/呼吸实际像素差异和输入边界；中文新增动作文案已纳入字库覆盖检查。原NVS结构与农田规则不变。

本机180项测试、Ruff、文档检查通过，ESP-IDF构建无新增编译warning；app为`0x174740` / 1,525,568字节，2 MiB app分区余`0x8b8c0` / 571,584字节（27%）。仅更新app，不擦NVS。相似度、可爱程度和实体动画观感仍以用户反馈为准。

## 十一的小窝：胖肚子、四肢与互动玩具

按用户本轮要求重画为48×48全身形象，放大到192px：加宽肚子与后腿，前腿、后爪分开画，保留虎斑额头、白鼻梁、白胸腹和环纹尾。关闭LVGL图片抗锯齿，整数倍显示像素。21张RGB565静态帧合计96,768字节（94.5 KiB）像素RAM，没有增加游戏线程或联网依赖。

“十一的小窝”作为第5页，触碰十一仍为摸摸；新增喂食小碗、逗猫棒/羽毛、弹动皮球和抬爪回应，每次互动6秒，只替换当前互动，不排队。需要人工确认、语音忙和Codex工作保持更高显示优先级。“十一的农场”移到独立第6页，网络页顺延为第7页；可从小窝“去小农场”和农场“回去陪十一”切换。原三块田、45秒成长、NVS命名空间与存档格式不变；宠物/玩具依旧离线运行。

## 花屏修复与照片参考素材

用户实机反馈花屏/卡顿后，串口实际捕获到`Draw bitmap failed: ESP_ERR_NO_MEM`、`spi transmit (queue) color failed`和CO5300发送失败。上一版21张48px精灵的96,768字节内部静态RAM挤占了显示DMA空间；先前只检查`MUSE_CONFIG_READY`不足以证明显示稳定，这是本轮修正的验收缺口。

- 动画展开缓冲改为显式`MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT`分配，不再放内部BSS；记录PSRAM占用与内部DMA余量。内存修复版app-only烧录后，串口持续观察未再出现显示内存/传输错误。
- 用内置imagegen直接参考用户提供的十一照片生成更细致的16格全身素材，结合本次实拍视频观察坐姿、白腿、大白胸、不对称白鼻梁、棕灰虎斑背和环纹尾。整理后的透明图集、生成提示词及重建说明见`firmware/esp32/assets/`；私人原图、视频未加入Git。
- 96×96图集量化为256色色表与索引，147,968字节const数据留在Flash；展开22个姿态共405,504字节，仅使用PSRAM。以2倍整数放大显示，沿用小窝/玩具/独立农场和旧存档，不增加PNG解码器或运行时模型。
- 新增CI内部RAM预算：BSS最多64 KiB、data+BSS最多96 KiB。原花屏版本124,368字节BSS会被拦截；当前实测BSS为27,600字节、静态内部RAM总计49,660字节。该守护不能替代DMA运行时验收。
- 本机183项测试、Ruff、文档检查通过；真实LVGL生产UI控制回调、玩具/农场跳转和66次姿态刷新通过（硬件层为模拟）。最终ESP-IDF app `0x1996f0` / 1,677,040字节，2MiB分区剩余`0x66910` / 420,112字节（20%）；不扩分区。
- 最终固件app-only烧录Flash hash通过。烧录后10秒日志显示0次显示错误、0次SPI传输错误；已请求用户在实体屏切页并点击玩具，继续核对串口。外观相似度与实体触控体验以用户反馈为准，USB语音和断电存档本轮未重验。

用户随后按要求查看第5页、切页并试玩逗猫棒/皮球，明确反馈“显示流畅，新形象更像了”。本轮显示恢复和形象改进获得实体反馈确认。最终固件额外55秒串口观察仍为0次显示错误、0次SPI错误；这段观察窗口没有捕获触控事件，因此触控/玩具结论依据用户确认，不能冒称串口记录了对应操作。

## 连续抬爪与10fps动作节奏

按用户“可以补帧，让动作更流畅”追加8张同体态抬爪素材，用于逗猫棒和皮球。每100ms推进一格，8格上行、顶端稍停、8格回落，避免高举直接跳回落地；玩具位置跟随动作逐步变化，互动总时长仍为6秒。等待确认/语音/Codex显示优先级及原农场存档不变。走路位移改为逐步左右移动，不再从+5px直接跳到-5px。

本轮尝试过程序运动插帧，但预览有重影，已弃用，未进入固件。当前使用内置imagegen生成的真实动作关键帧，保留原有待机与照片参考身份；舔爪、歪头、睡眠暂仍用原关键帧，没有声称所有动作均已补帧。已有timer调整为100ms，安静待机节奏通过tick换算保持，不新增线程。

原生测试检查6秒结束、8格范围、相邻帧只前进/后退一格；183项测试与Ruff通过。实际LVGL生产界面控制回调及66次刷新通过；ESP-IDF构建与内部RAM预算通过：BSS28,048字节、内部静态合计50,108字节。新增素材const仍在Flash，38张展开状态700,416字节仍显式放PSRAM。

app `0x1ab820` / 1,751,072字节，2MiB app分区余`0x547e0` / 346,080字节（17%）。已到原有80–85%体积关注区间；本轮记录资源变化、不扩分区，后续新增素材优先复用/裁剪。实体动作流畅度等待用户确认。

最终app-only烧录Flash hash通过，未擦NVS；烧录后12秒串口显示错误与SPI发送错误均为0。已请求用户试玩确认流畅度，未提前标记实体体验验收通过。
