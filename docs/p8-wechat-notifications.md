## 第一阶段：数据契约与隐私防线（先 Mac，再板端）
1. CAO 在**已授权的项目群**范围输出只读摘要。仅接收：稳定去重事件 ID、项目匿名标识/允许的显示代号、分级类别（@我/任务/决定/阻塞/其他）、计数、最近成功同步时间与 stale/unavailable 状态。**不得**返回群名、发送者、聊天正文、图片、头像、原始微信凭据；跨项目数据必须有权限隔离。
2. Mac Gateway 配置独立只读凭据，使用首轮静默基线和持久化观察游标；按稳定指纹去重，离线/重启/撤销授权不能重放旧提醒。API 无数据、过期、断连时显式显示 unavailable/stale，绝不假报 0 条。
3. 默认静默与勿扰；只有真正需要用户确认的高优先级项目事项成为提示候选。不得自动触发语音播报、Codex、微信发送或任何写操作。
4. ESP32 不存微信或 CAO 密钥，只显示计数、类别、最近同步时间、同步状态；保留 7 页、十一的小窝、农场与 USB/GPT/Serena 80。未经设备同意不自动烧录。

## 2026-10-10 实现与本机验证

- Gateway 新增严格白名单摘要 DTO；拒绝正文、发送者、群名等额外字段、跨 scope、重复 ID、不完整快照与非法时间。来源断开、撤销授权或过期时计数为未知，不伪装成 0。
- 私有 SQLite 仅存 scope/匿名事件 ID/类别/待查看游标，权限 0600。首次静默基线；重启及完整快照中的移除/重新出现不会重放；接收屏幕 `UI_PAGE inbox` 时标记已查看。语音播放期间未观察到的页面事件不会自动清除计数。
- 默认关闭，显式启用后每 60 秒读一次 CAO，不发声、不启动任务。`MUSE_WECHAT_TOKEN` 使用独立只读能力，不能复用执行或采集令牌。`MUSE_WECHAT_SCOPE_ID` 绑定当前用户、设备及授权项目/群组合；绑定变化需重新核对并更新本地 scope。
- CAO 配套独立分支 `codex/p8-wechat-summary`：新增 `GET /api/v1/personal-agent/wechat-notifications`。现有 communications 接口含正文，禁止回退。摘要只查询指纹与类别，按用户、设备、项目、精确群名与来源筛选；最近 30 天最多 1000 个完整事件，超限返回 unavailable，等待后续分页设计。
- CAO 仅读取采集器 `muse-readonly` 投影目录，不挂载 TraceMemo 密钥目录。投影每约 20 秒更新，超过 60 秒失效；完整成功批次（包括零消息）记录成功时间，失败批次立即使摘要 unavailable。成功采集超过 90 分钟显示 stale。类别沿用采集器已有标签，不代表模型已核实任务或 @本人。
- 本机既有三个授权群实际批次：59 条进入去重判断，第一次新增 3、重复 56、失败 0；复验新增 0、重复 59、失败 0。真实安全摘要 558 个匿名事件；首次及重复读取均为 0 条待查看。此数字为首次基线后的本地待查看增量，**不是微信官方未读数**。
- 独立 CAO 测试服务位于回环端口 8091，复用只读数据卷；原执行服务未替换。可选 `MUSE_WECHAT_BASE_URL` 仅用于分阶段本机部署，仍只接受 loopback HTTP。令牌/绑定/采集记录/游标仅保存在本机忽略位置。
- Muse 205 项测试通过；CAO 370 项 Python 测试和 40 项前端测试通过。实际 LVGL 主机渲染检查了 available/stale/unavailable 三种消息页，并回归宠物和农场控件；主机渲染不等于实机验收。
- 固件在锁定 ESP-IDF/BSP 上构建，应用分区剩余约 16%，内部 BSS 28,080 / 65,536 字节，内部静态 RAM 50,140 / 98,304 字节。没有新增动画资源或扩分区。
- 实体烧录、显示/切页/断联与 USB 语音回归：待本轮真实设备确认；不得用模拟事件冒充微信新增消息。两个 PR 保持 Draft，不合并。

### 配置

先完成 CAO 专用只读源与授权范围核对，再在本机 `.env` 设置
`MUSE_WECHAT_ENABLED=true`、`MUSE_WECHAT_TOKEN`、`MUSE_WECHAT_SCOPE_ID`。
现有 `MUSE_CAO_ENABLED` 也需启用。游标默认在用户私有数据目录；无需微信账号密码或新增云端模型 Key。
